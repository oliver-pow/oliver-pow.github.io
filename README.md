# Engineering Portfolio Template

## Run locally
Open `index.html` in a browser. No build tools or installation are required.

## Add projects
1. Open `projects.js`.
2. Copy one complete project object (from `{` to `}`).
3. Paste it after the previous object, adding a comma between objects.
4. Change the title, category, date, summary, tools, details, challenges, outcome and link.
5. Save and refresh the browser.

There is no fixed project limit. The project cards and category filters are generated automatically.

## Add project photographs
1. Create an `images` folder beside `index.html`.
2. Put your image in that folder, e.g. `esp32-console.jpg`.
3. Set that project's `image` value to `images/esp32-console.jpg`.

Use your own photos and screenshots where possible. Keep image file sizes reasonable.

## Personalize the site
- Search `Your Name`, `your.email@example.com` and `yourusername` in `index.html` and replace them.
- Edit the introduction and About section in `index.html`.
- Edit the skill tags in `index.html` to list skills you can genuinely demonstrate.
- Change colors and layout in `style.css`.

## Publish for free
A straightforward option is GitHub Pages:
1. Create a GitHub repository.
2. Upload the contents of this folder to the repository's root.
3. In repository Settings > Pages, choose deployment from the `main` branch and `/ (root)`.
4. GitHub will provide your website address.

The template uses Google Fonts when an internet connection is available; the rest of the site works without a build step.
